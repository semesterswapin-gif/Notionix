# Notionix

Notionix is a lightweight, browser-based notes app with a focused editor and
local persistence.

## Features

- Create, edit, and delete notes
- Search note titles and content
- Format content with bold, italic, underline, and lists
- Automatically save notes in the browser's `localStorage`
- Responsive, accessible interface

## Run locally

No build step or dependencies are required. Open
[`index.html`](./index.html) in a modern web browser.

## Project files

- [`index.html`](./index.html) - application markup
- [`style.css`](./style.css) - visual styling
- [`script.js`](./script.js) - note management and editor behavior
